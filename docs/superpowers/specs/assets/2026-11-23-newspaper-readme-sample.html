Profile

Engineer Ships Products by Day, Builds Toys by Night

Four-plus years of production web apps, the AI features inside them, and a growing habit of making software look like something else.

Pyae Phyo Win is a full-stack software engineer who has spent more than four years building web apps that real businesses run on: CRMs, point-of-sale systems, and order tools for shops that sell online. Lately the work has moved into the AI features inside those apps, including RAG, LLM assistants and data tooling.

When the day’s work ships, the side projects start. They include a UI library dressed as a newspaper and a browser extension built after logging out one time too many.
